# 💻 Portfólio Pessoal — Álvaro Guimarães

Este projeto foi desenvolvido como parte de um **desafio de estudo**, com o objetivo de colocar em prática conhecimentos de desenvolvimento web e programação.

O portfólio apresenta informações sobre mim, minhas habilidades e alguns projetos desenvolvidos durante os meus estudos.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Java
- Git
- GitHub
- GitHub Pages

## 📂 Projetos

### 🛡️ Detector de Golpes Digitais

Aplicação que analisa mensagens e procura sinais comuns de possíveis golpes digitais.

O projeto foi inicialmente desenvolvido em **Java** e posteriormente ganhou uma versão web utilizando **HTML, CSS e JavaScript**.

### 🧮 Calculadora

Calculadora desenvolvida para praticar operações matemáticas e manipulação de elementos da página utilizando **JavaScript**.

### ✅ Lista de Tarefas

Aplicação que permite adicionar, concluir e excluir tarefas.

O projeto utiliza **localStorage** para manter as tarefas guardadas no navegador mesmo após atualizar a página.

## 🎯 Objetivo do projeto

O objetivo deste portfólio é praticar conceitos de:

- Estruturação de páginas com HTML
- Estilização e responsividade com CSS
- Programação e interatividade com JavaScript
- Lógica de programação
- Desenvolvimento com Java
- Controle de versão com Git
- Utilização do GitHub
- Publicação de páginas com GitHub Pages
